WATER SUPPLY MANAGEMENT SYSTEM - COMPLETE API DOCUMENTATION (api.txt)
================================================================================
Base URL: /api/v1
Default Port: 5000 (http://localhost:5000/api/v1)
Total Endpoints: 43

Authentication Schemes:
- Public: No authentication required.
- JWT Bearer Token: Sent in header "Authorization: Bearer <token>" or "?token=<token>" query param.
- Role Access: Enforced by middleware:
  - Admin (Platform Administrator)
  - Vendor (Water Distributor / Supplier)
  - Agent (Field Delivery Agent / Driver)
  - Customer (End-consumer ordering water bottles)

--------------------------------------------------------------------------------
- Method: POST
- Endpoint: /api/v1/auth/verify-otp
- Access Level: Public
- Description: Verifies Firebase ID Token passed from client after phone SMS OTP.
  Extracts the verified phone number. Checks if user exists:
  - If existing Customer: returns active JWT auth token and customer profile.
  - If existing Delivery Agent: returns active JWT token, agent profile, and vendorId.
  - If new phone number: returns `isNewUser: true` prompting frontend to collect
    customer Name and Address.
- Request Body:
  {
    "idToken": "FIREBASE_ID_TOKEN_STRING"
  }
- Success Response (Customer - 200 OK):
  {
    "success": true,
    "isNewUser": false,
    "token": "eyJhbGciOiJIUzI1NiIsIn...",
    "user": {
      "id": "6643c3...",
      "name": "Rahul Sharma",
      "phone": "9876543210",
      "role": "customer",
      "address": "Flat 402, Green Valley Apartments",
      "addresses": ["Flat 402, Green Valley Apartments"]
    }
  }
- Success Response (Delivery Agent - 200 OK):
  {
    "success": true,
    "isNewUser": false,
    "token": "eyJhbGciOiJIUzI1NiIsIn...",

2.7. Forgot Password Request
--------------------------------------------------------------------------------
- Method: POST
- Endpoint: /api/v1/auth/forgot-password
- Access Level: Public
- Description: Generates a secure random 15-minute password reset token for Admin
  or Vendor, saves SHA-256 hash to database, and sends a reset link via email.
- Request Body:
  {
    "email": "vendor@aquaflow.com"
  }
- Success Response (200 OK):
  {
    "success": true,
    "message": "Email sent"
  }

2.8. Reset Password
--------------------------------------------------------------------------------
- Method: PUT
- Endpoint: /api/v1/auth/reset-password/:token
- Access Level: Public
- Description: Validates password reset token, checks expiration date, sets new
  password (automatically hashed by pre-save hook), and returns fresh JWT token.
- URL Parameters:
  `token`: Plaintext reset token from the reset URL.
- Request Body:
  {
    "password": "NewSecurePassword456!"
  }
- Success Response (200 OK):
  {
    "success": true,
    "token": "eyJhbGciOiJIUzI1NiIsIn...",
    "message": "Password updated successfully"
  }

7.2. Update Order Status (Fulfill Pending Request)
--------------------------------------------------------------------------------
- Method: PUT
- Endpoint: /api/v1/orders/:id/status
- Access Level: Private (Vendor or Agent - Requires Active Vendor Subscription)
- Description: Processes a customer's pending delivery request or cancels an order.
  Authorized for both Vendor and assigned Delivery Agent.
  - When updated to `delivered`: verifies inventory stock, deducts product stock,
    adds total amount to customer debt, records bottles delivered and returned,
    and optionally logs cash collection on delivery (tracking `collectedByAgentId` when agent fulfills).
  - When updated to `cancelled` (from `delivered`): automatically restocks product inventory,
    reverses customer ledger balance, marks linked payments as `cancelled` (removing phantom debt from
    the agent's shift collection), and resets unsettled empty jar records.
- URL Parameters: `id`: Order ObjectId
- Request Body (JSON):
  {
    "status": "delivered",          // "delivered" or "cancelled"
    "bottlesDelivered": 2,
    "bottlesReturned": 1,
    "cashCollected": 160,           // Used by Agent (capped at delivery charge & customer due balance)
    "paymentMethod": "cash",        // Optional for Vendor: "cash" or "due"
    "paymentAmount": 160,           // Optional for Vendor
    "deliveryNotes": "Left at front door" // Optional notes / remarks
  }
- Success Response (200 OK):
  {
    "success": true,
    "data": { ...updated order document... }
  }
